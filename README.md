# tahfidz_tracker
*Tahfidz Tracker* adalah aplikasi web interaktif berbasis React dan Firebase untuk memantau hafalan Al-Qur'an santri. Sistem ini memudahkan asatidz mencatat setoran hafalan, absensi harian, dan evaluasi tasmi' bulanan secara *real-time*. Tersedia juga akses khusus bagi wali santri untuk memantau progres anak dari rumah.
